# Branches
- Before creating a branch, or before pushing one to a remote, ask me what to name it. Never pick the name yourself.
- Branch names are `lyte/<topic>`, never `claude/...`.
- No hashes, random suffixes, or session IDs in branch names.
- If the current branch has an auto-generated name, ask me for a name and rename it (`git branch -m lyte/<topic>`) before the first push.
